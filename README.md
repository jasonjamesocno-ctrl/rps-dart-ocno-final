 This is a simple two-player Rock, Paper, Scissors game created using Dart.

    The program allows two players to enter their names and choose between rock, paper, or scissors. It checks whether the entered move is valid, determines the winner of each round, keeps track of the scores, and allows the players to play another round. At the end of the game, the final scores and overall winner are displayed.

## How to Run

1. Open the project folder in VS Code.
2. Make sure Dart is installed on your computer.
3. Open the terminal in VS Code.
4. Make sure you are inside the project folder.
5. Run the program using:

```bash
dart rock_paper_scissors.dart
